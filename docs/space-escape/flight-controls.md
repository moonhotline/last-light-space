# 独立飞船与水星探索

出生区附近停靠轻型战机与星际巡航舰，无需材料或维修。两船独立保存位置、乘员、驾驶员、目的地与导航模式；同一房间的玩家可以分别驾驶。

| 操作 | 键位 |
| --- | --- |
| 登船；停稳后下船 | E |
| 前后与侧向推进 | WASD |
| 上升；下降 | 空格；X |
| 减速；低速机动 | Shift |
| 转向与抬头 | 鼠标；左右方向键与 I 抬头 |
| 选择水星并释放鼠标打开导航 | N |
| 自动巡航 | O |
| 当前球面位置着陆辅助 | Z |
| 第一／第三人称 | V |

导航面板也提供推荐点、赤道、南极三个水星航路入口。这三个入口便于找到不同位置，手动飞行和就地着陆辅助可用于整个球面。

选目的地不会自动出发。开启巡航后，飞船按加速度与制动距离飞向目标上空，等待玩家选择着陆辅助或手动下降。WASD、升降或减速输入会取消辅助；松开后继续保持手动。只有本船驾驶员可改变目标、模式及驾驶输入。

飞船使用同一套运动与防撞处理执行手动及辅助驾驶。盆地地形只在其真实范围内参与接地；球面用星心方向确定净空、船底朝向和下船位置。防撞保护限制朝地速度并阻止穿透，不消耗耐久或摧毁飞船。船体摆正且低速接地才算着陆。

抵达水星不会结束游戏。下船后角色与已招募的 Blerk 使用球面重力，飞船停在实际降落位置。驾驶员离舱、召回或断线时，本船下一位乘客接替驾驶；另一艘船不受影响。

自动化验证：

```sh
npm run space:test
npm run space:build
# 分别启动前端与真实 PartyServer，测试只使用 UI、键盘和只读遥测
SPACE_WEB_PORT=5186 npm run space:dev
npx wrangler dev --port 1998
SPACE_WEB_URL=http://127.0.0.1:5186 npx playwright test \
  --config playwright.space.config.ts tests/space-escape-ui/flight.spec.ts \
  --output frontend/space-escape/.runtime/flight-results
```

多人服务与前端必须使用匹配的版本：权威状态从单个 `adventure.ship` 改为 `adventure.ships`，玩家通过 `shipId` 关联所乘飞船。原先“收集材料后才能驾驶、到达回声林地结束游戏”的验收已由直接登船和持续探索流程替代，采集、铭文和战斗仍作为可选内容保留。
