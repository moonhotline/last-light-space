# Texture and asset attribution

- `earth.jpg`: Earth atmosphere texture, downloaded 2026-09-13 from https://threejs.org/examples/textures/planets/earth_atmos_2048.jpg (Three.js example assets; https://github.com/mrdoob/three.js, MIT).
- `moon.jpg`: Moon surface texture, downloaded 2026-09-13 from https://threejs.org/examples/textures/planets/moon_1024.jpg (Three.js example assets; same source repository).
- `explorer.glb`, `beacon.glb`, `observatory.glb`, `lander.glb`: original models generated by this project's Blender Python script.
- `planet-ambient.wav`, `planet-awake.wav`, `planet-finale.wav`: original synthesized music generated by this project's Node script.
- Terrain, astronomical sky, gas giant, rings, crystals and particles: original procedural game assets.

The astronomical scale and trajectories are fictional and chosen for the experience.

- `explorer-v2.glb`, `skiff.glb`, `dawn-lab.glb`: original v0.2.0 models generated by `scripts/generate_echo_assets.py`; no downloaded character, ship, or lab models are used.
- `explorer-v3.glb`: original v0.3.0 PEREGRINE-07 Armature model generated by `scripts/generate_explorer_v3.py`; the editable `.blend`, Cycles render and motion inspection report are included in the repository.
- `explorer-v4.glb`: High-fidelity EVA spacesuit model based on "Animated Floating Astronaut in Space Suit Loop" by LasquetiSpice (CC-BY 4.0; https://sketchfab.com/3d-models/animated-floating-astronaut-in-space-suit-loop-e2c4b146e58141e4b87917456a9970b1), optimized, retargeted and rescaled by `scripts/generate_explorer_v4.py`.
- Echo Grove vegetation, archive panels, material patina and new feedback effects are original procedural assets.
